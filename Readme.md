# Что делает трек хитом? Анализ самых прослушиваемых песен Spotify за 2023 год

Итоговый проект по курсу «Анализ данных на Python».

Берём топ самых стримимых треков Spotify за 2023 год и пытаемся понять, есть ли у хитов
что-то общее: важен ли темп и тональность, помогает ли попадание в плейлисты,
в какой месяц выгоднее выпускать песню и правда ли, что мажор слушают охотнее минора.

## Данные

За основу взят датасет [Most Streamed Spotify Songs 2023](https://www.kaggle.com/datasets/nelgiriyewithana/top-spotify-songs-2023)
с Kaggle: 953 трека, 24 колонки. Внутри число прослушиваний, позиции в чартах и
плейлистах четырёх платформ (Spotify, Apple Music, Deezer, Shazam) и звуковые
характеристики трека: bpm, тональность, danceability, energy и т.д.

Датасет сырой: часть числовых колонок записана строками (`streams`,
`in_deezer_playlists`, `in_shazam_charts`), в `key` 95 пропусков, в
`in_shazam_charts` ещё 50, а в одной строке вместо числа прослушиваний вообще
лежит кусок текста про BPM. Так что чистить есть что.

В датасете нет жанра, поэтому на этапе очистки обогащаем его через сторонний
[iTunes Search API](https://itunes.apple.com/search) (без ключа): по названию трека и
первому исполнителю тянем `primaryGenreName`. Запросы кэшируются в `data/itunes_cache.json`.

## Гипотезы

1. Треки в мажорной тональности в среднем набирают больше прослушиваний, чем в минорной.
2. Число плейлистов, в которые попал трек, связано с количеством стримов сильнее, чем любая звуковая характеристика.
3. У релизов есть сезонность: треки, выпущенные в начале года и перед летом, набирают больше.
4. Чем больше соавторов у трека (artist_count), тем выше его шансы попасть в чарты.

По ходу анализа список можем дополнить.

Сверх базовых гипотез делаем продвинутую часть: декомпозицию временного ряда
релизов на тренд и сезонность (`statsmodels.seasonal_decompose`).

## Структура проекта

```
data/
  spotify-2023.csv        - исходный датасет с Kaggle
  spotify-2023-clean.csv  - очищенная версия (создаётся ноутбуком raw.ipynb)
  raw.ipynb               - загрузка и очистка данных
notebooks/
  analysis.ipynb          - анализ и графики
.gitignore
Readme.md
requirements.txt
```

## Как запустить

1. Поставить зависимости: `pip install -r requirements.txt`
2. Запустить ноутбуки по порядку: сначала `data/raw.ipynb`, потом `notebooks/analysis.ipynb`.
